# March-Project-
Coffee Shop Project

--About the Project
The project focuses on identifying ways to improve sales and gain insights into product and store performance.

--Project Description
The Bright Coffee Shop Project explores how data can be used to enhance decision-making in a coffee shop environment. It involves analyzing raw data sourced from Excel CSV files.

--Project Planning
Planning materials and visual tools used to design the project include:
Miro
Canva

--Data Processing
Data was processed using Databricks, with SQL used for coding and analysis.

--Presentation
The presentation was created using Canva and included key insights and recommendations for the coffee shop.
